SYED GLOBAL FINANCE TRACKER — APP + SOURCE CODE

OPEN THE APP
1. Extract this ZIP file.
2. Double-click Syed-Global-Finance-Tracker.html to use the app in a browser.

EDIT THE SOURCE CODE
The Source Code folder contains the editable app files:
- index.html: page structure and starting transaction data
- styles.css: app appearance
- app.js: app behavior and calculations
Keep these three files together in the same folder. Open Source Code/index.html to run this version.

The HTML file is self-contained and also includes the app code. The app saves entries in the browser on the device where it is used; it does not automatically sync entries between devices.
